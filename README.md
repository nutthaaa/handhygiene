# CleanHands+ React Frontend

ระบบ Dashboard และแบบประเมินการล้างมือ พัฒนาด้วย React + Vite

## เริ่มใช้งาน

```powershell
npm install
npm run dev
```

## URL

- Dashboard: `http://localhost:3000/`
- แบบประเมิน: `http://localhost:3000/survey`

## การทำงาน

- หัวข้อและตัวเลือกแบบประเมินถูกล็อกไว้ใน `src/data/constants.js`
- แบบประเมินไม่อ่านหรือซิงก์ข้อมูลจาก Excel
- แผนกเป็นช่องกรอกข้อความ
- ตัวเลือกอื่นใช้ Radio card
- คำตอบเก็บใน `localStorage` ของ browser
- Dashboard ใช้เฉพาะข้อมูลที่ส่งจากแบบประเมิน
- รองรับนำเข้า Excel จาก CSI โดยเลือกเดือนก่อนนำเข้า
- ข้อมูล CSI จะรวมกับข้อมูลแบบประเมินใน Compliance รายเดือนและ YTD
- CSI ไม่มีข้อมูล Moment, บุคลากร และครบ 6 ขั้นตอน จึงไม่นำไปคำนวณตัวชี้วัดเหล่านั้น
- การนำเข้า CSI เดือนเดิมซ้ำจะแทนที่ข้อมูลเดือนเดิม
- ส่งออกผลลัพธ์เป็น Excel พร้อมชีต Summary ได้

สูตร Compliance:

```text
(ครบ + ไม่ครบ) / จำนวนประเมินทั้งหมด × 100
```

ระบบยังเป็น frontend-only ข้อมูลจึงอยู่เฉพาะ browser ของเครื่องที่ใช้งาน
